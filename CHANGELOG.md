# Changelog

## 0.3.0 — 2026-10-15

- Reorganized the full editor and menu bar controls around the Hush and Snip visual style, with matching materials, spacing, and control sizes.
- Added **Command–W** to close the full settings window while leaving Glim running.
- Added an **Automatically update from GitHub** switch in General settings. Glim checks for new releases daily, asks before installing, and verifies the release ZIP and app before replacing the current copy.

## 0.2.3 — 2026-10-14

- Improved gamma and contrast curves so near-black detail can be lifted without crushing nonzero shadows.
